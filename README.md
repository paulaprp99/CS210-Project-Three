CS210 Project Three - Corner Grocer
Summarize the project and what problem it was solving.

For this project, I created a C++ program for a grocery store. The program reads a file with grocery items and counts how many times each item appears. The user can search for an item, see a list of all the items, or see a histogram using stars. The main goal was to make it easier to see which items were purchased the most.

What did you do particularly well?

I think I did well organizing my code and making the menu easy to use. I separated my code into different files and functions instead of putting everything in one place. I also added a way to check if the user enters something wrong in the menu so the program does not just stop working.

Where could you enhance your code?

I think I could improve the search option. Right now, the user has to type the item correctly for the program to find it. I could change it so uppercase and lowercase letters do not matter. I could also add more checks for user input. This would make the program easier to use.

Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?

The hardest part for me was reading the information from the file and getting the program to count each item correctly. I also had some problems getting the program to find the input file. I fixed these problems by testing my code, checking where my files were saved, and going back to examples from the course. I also used Visual Studio to help me find errors in my code.

What skills from this project will be particularly transferable to other projects or course work?

I learned more about using classes, functions, loops, maps, and files in C++. I also learned that separating code into different files can make a program easier to work with. I think I will use these skills again in other programming classes and projects.

How did you make this program maintainable, readable, and adaptable?

I separated my program into different files and used different functions for each part of the program. For example, I have functions for reading the file, searching for an item, showing all the items, and showing the histogram. I also added comments to my code. I think this makes the program easier to read and easier to change later.
